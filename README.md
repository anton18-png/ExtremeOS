> ⚠️ **ВНИМАНИЕ:** Программа создана для настройки **свежеустановленной системы**. При запуске на рабочей / настроенной / оптимизированной ОС возможны проблемы.

> **Требования:** Windows 11 Pro 24H2+
>
> **Рекомендация:** отключите интернет перед запуском для беспроблемного удаления Edge, WebView2 и Defender.

#

### 🎯 Что такое ExtremeOS?

**ExtremeOS Wizard** — это универсальный установщик, объединяющий **три** модификации Windows 11 с разной степенью вмешательства в систему:

| Модификация | Степень вмешательства | Описание |
|-------------|----------------------|----------|
| **WinClick** | 🟠 Средняя | Сбалансированная оптимизация. Удаление мусора, приложений, настройка параметров. |
| **ReviOS** | 🟠 Средне-высокая | Баланс между производительностью и стабильностью. Сохранение критических служб. |
| **AtlasOS** | 🔴 Высокая | Агрессивная оптимизация. Удаление телеметрии, служб, компонентов. Максимальная производительность для игр. |
| **ExtremeOS** | 🔴 **Экстремальная** | **Самые радикальные твики.** Массовое удаление служб, жёсткие настройки реестра, полная зачистка системы. |
