### 🎯 Что такое ExtremeOS?

**ExtremeOS** — это универсальный установщик, объединяющий **три** модификации Windows 11 с разной степенью вмешательства в систему:

| Модификация | Степень вмешательства | Описание |
|-------------|----------------------|----------|
| **WinClick** | 🟠 Средняя | Сбалансированная оптимизация. Удаление мусора, приложений, настройка параметров. |
| **AtlasOS** | 🔴 Высокая | Агрессивная оптимизация. Удаление телеметрии, служб, компонентов. Максимальная производительность для игр. |
| **ExtremeOS** | 🔴⚫ **Экстремальная** | **Самые радикальные твики.** Массовое удаление служб, жёсткие настройки реестра, полная зачистка системы. |

> **ExtremeOS — НЕ базовые и НО безопасные твики.** Это радикальное вмешательство в систему для максимальной производительности ценой функциональности.

# 🔵 МОДИФИКАЦИЯ WINCLICK (13 шагов)

### 🗑️ 1. Удаление мусора
- Удаление файлов обновлений Windows
- Удаление файлов обновлений браузера Edge
- Удаление кэша Microsoft Store
- Удаление кэша Проводника
- Удаление устаревших компонентов в хранилище WinSxS
- Удаление лишних папок на диске С `(Windows.old, PerfLogs, inetpub)`
- Удаление старых драйверов
- Удаление ShellBags

> Последние два пункта добавлены на случай, если запускаете WinClick не на новой системе.

---

### 📦 2. Удаление всех предустановленных приложений
- Удаление всех предустановленных UWP-пакетов
- Удаление Microsoft Store
- Удаление OneDrive
- Удаление Подключение к удаленному рабочему столу

> 💡 **Восстановить Microsoft Store можно командой:** `wsreset -i`

### 🌐 3. Удаление браузера Edge и WebView2
- Удаление браузера Edge
- Удаление компонента Edge WebView2

> 💡 **Альтернативные портативные браузеры:** [Cent](https://www.centbrowser.com/), [CatsXP](https://www.catsxp.com/), [Floorp](https://floorp.app/)

> 💡 Компонент `Язык сценариев VBScript` может быть нужен для установки некоторых программ (Epic Games) и драйверов (AMD). При проблемах — установите его в `Настройки > Система > Дополнительные компоненты`.

### 📦 Обновлённые компоненты:

#### 🚀 Custom DirectX V2.0

Помните мою кастомную версию DirectX для сборки Windows 11 под названием ProOS?

Ту самую, где я мучительно пытался заставить систему подружиться с компонентами от Microsoft, потому что установить DirectX обычным способом было просто невозможно?

**Так вот — вышла вторая версия! 🔥**

**Коротко напомню суть первой версии:**
Я решил проблему на ProOS и сделал кастомный установщик, который **СМОЖЕТ** установить DirectX на эту сборку. А ещё после установки применял твики для оптимизации DirectX.

**🎯 Кому залетит?**

Тем, кто хочет установить DirectX:
- ✅ **БЕЗ** надоедливого «Далее → Далее → Далее» во время установки
- ✅ **БЕЗ** того, чтобы после установки заново лезть и вручную выполнять оптимизацию

**Итог:**
Нажал **один раз** — получил готовый, уже оптимизированный DirectX.  
Без лишних телодвижений и без скучных окон.
